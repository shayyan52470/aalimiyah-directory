# Data guide

Each row represents one distinct programme. If an institution offers materially different online, campus, full-time, or part-time tracks, create separate rows.

## Core rules

- Use UTF-8 CSV with the exact header order generated by `scripts/data_schema.py`.
- Separate multiple values with semicolons, never commas. Commas can then remain part of ordinary titles.
- Use `YYYY-MM-DD` dates.
- Leave unknown facts blank. Do not turn “likely” or “probably” into a categorical fact.
- A `published` record must have a programme name, official URL, and source URL.
- Prefer official institution pages, current syllabi, admissions pages, and fee schedules.
- Do not include personal details, private correspondence, unsourced rankings, or unattributed opinions.

## Fields

| Field | Purpose | Format or accepted values |
|---|---|---|
| `id` | Permanent record identifier | Lowercase kebab-case; do not change after publication |
| `institution` | Provider’s public name | Required |
| `programme_name` | Exact advertised programme name | Required for published records |
| `programme_type` | Broad type | For example `Aalimiyah`, `pre-Aalimiyah`, `degree`, `specialisation` |
| `status` | Publication state | `draft`, `published`, `archived` |
| `delivery_mode` | Primary participation method | `online`, `in-person`, `hybrid`, `unknown` |
| `institution_location` | Institution or campus base | Free text, even for online programmes |
| `country` | Institution or campus country | Full English country name |
| `timezone` | Teaching timezone | Prefer an IANA value such as `Australia/Melbourne` |
| `languages` | Languages used to teach | Semicolon-separated; distinguish teaching language from subjects |
| `arabic_entry_level` | Arabic assumed at entry | A short sourced description, not a guessed CEFR level |
| `gender` | Published student availability | `open`, `men`, `women`, `separate`, `unknown` |
| `study_load` | Expected intensity | `full-time`, `part-time`, `flexible`, `unknown` |
| `duration_years` | Nominal programme duration | Number where possible, such as `6` or `5.5` |
| `schedule` | Live class pattern | Include days, times, timezone and whether recordings exist |
| `curriculum` | Named curricular structure | For example `Dars-e-Nizami`; blank if not stated |
| `jurisprudence_school` | Stated school(s) of law | Semicolon-separated; do not infer from geography |
| `theology_school` | Stated theological orientation | Semicolon-separated; distinguish an inference in notes |
| `qualification` | Award or certificate | Use the provider’s exact terminology |
| `accreditation` | External recognition claim | Name the accrediting or awarding body and scope |
| `entry_requirements` | Admissions prerequisites | Concise sourced summary |
| `tuition_amount` | Numeric fee | Digits and decimal point only where possible |
| `tuition_currency` | Fee currency | ISO 4217 code, such as `AUD`, `GBP`, `USD` |
| `tuition_period` | What the amount covers | For example `year`, `term`, `month`, `programme` |
| `tuition_notes` | Important fee context | Discounts, registration charges, estimates, or uncertainty |
| `financial_aid` | Published assistance | Scholarship or payment-plan summary |
| `subjects` | Areas formally taught | Semicolon-separated controlled names |
| `texts` | Named books or texts | Semicolon-separated; retain recognisable transliteration |
| `tags` | Cross-cutting discovery labels | Semicolon-separated controlled slugs |
| `official_url` | Main programme page | Full HTTP(S) URL |
| `syllabus_url` | Direct curriculum or syllabus page | Full HTTP(S) URL |
| `source_urls` | Evidence for the record | Semicolon-separated HTTP(S) URLs |
| `last_verified` | Most recent human source check | `YYYY-MM-DD` |
| `notes` | Restrained public clarification | Never use for personal comparison notes |

## Subject vocabulary

Use stable, reader-friendly subject names. Start with this vocabulary and extend it through review rather than creating spelling variants:

`Arabic language`; `Arabic literature`; `Arabic grammar`; `Morphology`; `Rhetoric`; `Qur’an`; `Tajwid`; `Tafsir`; `Qur’anic sciences`; `Hadith`; `Hadith methodology`; `Fiqh`; `Usul al-fiqh`; `Aqidah`; `Sirah`; `Islamic history`; `Logic`; `Inheritance`; `Spirituality`; `Research methods`; `Comparative religion`; `Da'wah`; `Contemporary studies`.

Subjects answer “what is taught?” A school of law or teaching language belongs in its dedicated field, not in `subjects`.

## Tag vocabulary

Tags answer “what useful characteristic has no dedicated column?” Use lowercase kebab-case. Initial tags include:

- `dars-nizami`
- `live-classes`
- `recordings-available`
- `self-paced`
- `residential`
- `foundation-year`
- `specialisation`
- `university-programme`
- `community-submitted`

Avoid tags that duplicate `delivery_mode`, `study_load`, `gender`, languages, subjects, or schools of law. New tags should be documented here in the same pull request.

## Editorial distinctions

### Qualification and accreditation

A provider-issued Aalimiyah certificate is a qualification claim. Accreditation is a separate claim about recognition by another body. Never convert one into the other.

### Institution location and delivery mode

An online provider may still be based in a country and teach in a particular timezone. Record all three separately.

### Verification

`last_verified` means a human opened the cited source and checked the record on that date. An automated Sheet export must not update it.
