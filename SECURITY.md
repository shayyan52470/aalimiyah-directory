# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub’s private vulnerability reporting feature on the repository’s **Security** tab.

Include the affected file or workflow, steps to reproduce the problem, its likely impact, and any suggested mitigation. Please do not test against accounts, systems, or data that you do not own.

## Sensitive information

This project should never contain Google credentials, GitHub tokens, private contact details, or unpublished research notes. Repository secrets belong in GitHub Actions secrets and must not be placed in source files, issues, logs, or pull requests.

The public Google Sheet tab should contain only columns intended for publication. Keep private research and personal comparison notes in a separate, unpublished tab or workbook.
