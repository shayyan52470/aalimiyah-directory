Know a programme we should include?

Submit the public facts and their sources. Nothing is added automatically—a maintainer checks each suggestion before it reaches the directory.

  1. 1

    Check the directory

    Search for the institution first. Existing programmes can be corrected through the same form.

  2. 2

    Share reliable sources

    Use the institution’s official programme or syllabus pages wherever possible. Please do not submit private contact information.

  3. 3

    We review the proposal

    The submission becomes a public GitHub issue. A maintainer verifies it and proposes the CSV change in a pull request.
